# 🏥 Sai Balaji Inventory & Revenue Intelligence
A high-performance, cloud-integrated management system built for Sai Balaji. This application handles everything from critical inventory tracking to advanced fiscal analytics.

## 🚀 Key Features
*   **💎 Revenue Velocity Intelligence**: Deep fiscal analytics with interactive drill-down capabilities (Year ➔ Month ➔ Day).
*   **📦 Smart Inventory Flux**: Real-time tracking of medicine stock with automated movement audit logs.
*   **📑 Clinical Session Management**: Seamless management of patient clinical sessions, invoices, and drug prescriptions.
*   **🛡️ Integrity Shield**: Automated database cleanup ensuring that deleting a patient record wipes all associated orphaned data securely.
*   **📱 PWA Ready**: Optimized for desktop and mobile use with offline-capable architecture.
*   **💬 SMS Integration**: Automated daily revenue reporting sent directly to stakeholders.

## 🛠️ Technology Stack
*   **Framework**: Next.js 15+ (App Router)
*   **Database**: PostgreSQL / Prisma ORM
*   **Styling**: Tailwind CSS & Glassmorphism UI
*   **Analytics**: Custom high-fidelity charting engine
*   **Deployment**: Vercel Edge Network

## ⚡ Quick Start
1.  **Clone the repo**:
    ```bash
    git clone https://github.com/Kavhein/sai-balaji-inventory.git
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Sync Database**:
    ```bash
    npx prisma db push
    ```
4.  **Launch Intelligence Dashboard**:
    ```bash
    npm run dev
    ```
